# Convite Digital - Vanessa & Ronaldo

Convite digital de casamento desenvolvido com HTML, CSS e JavaScript puro, com foco em experiência mobile-first, animação de abertura em formato de envelope, contagem regressiva, seção de local, lista de presentes com QR Code e identidade visual elegante em marfim, dourado e verde sálvia.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abrir `index.html` diretamente no navegador.

ou

Utilizar Live Server.

  css/

## Descricao do projeto

O projeto apresenta uma tela inicial com envelope animado e selo interativo. Apos a abertura, o convite revela uma experiencia vertical com hero, mensagem dos noivos, data e horario, local com ilustracao em aquarela, contagem regressiva, lista de presentes com QR Code e rodape.
